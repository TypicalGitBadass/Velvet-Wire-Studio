# Velvet Wire Studio 0.1.0

Velvet Wire Studio is an offline-first Windows desktop application for authoring and exporting cinematic conversation scenes.

## What's included

- Character and conversation authoring
- Cinematic In-Game IM presentation
- Player Replies
- Project Music and custom message sound effects
- PNG export
- MP4 export with 30 FPS and 60 FPS settings
- Portable `.velvetwire` Project Format v2

## Installation

Download `Velvet-Wire-Studio-Setup-0.1.0.exe`, verify it against `SHA256SUMS.txt`, and run the installer.

## Windows unsigned-build notice

This initial build is unsigned. Windows may display Unknown Publisher or Microsoft Defender SmartScreen. Continue only if the installer came from this official release and its checksum matches. Do not disable Windows security features.

## Updates and Repair

Future installers are designed to upgrade an existing installation in place. Running the same-version installer provides Repair/Reinstall. Standard Windows Installed Apps uninstall remains supported.
