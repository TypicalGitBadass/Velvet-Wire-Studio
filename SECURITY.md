# Security Policy

## Supported release

Security reports currently apply to Velvet Wire Studio 0.1.0, the latest prepared public release.

## Reporting a vulnerability

Use the repository's GitHub Security Advisories interface to submit a private vulnerability report. Include the affected version, a concise impact description, reproduction steps, and any relevant logs with personal information removed.

Do not publish exploit details, private user data, credentials, or sensitive project files in a public issue. If private reporting is not yet enabled, wait for the owner-provided private contact method shown on the repository rather than disclosing the issue publicly.

The owner will review reports and determine acknowledgement, remediation, and disclosure timing. This policy does not promise a specific response or fix deadline.
