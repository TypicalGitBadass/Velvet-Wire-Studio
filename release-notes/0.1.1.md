# Velvet Wire Studio 0.1.1

Maintenance update for Windows desktop export reliability.

- Improves background-process lifecycle by starting local render infrastructure only when needed.
- Reduces unnecessary renderer activity while Velvet Wire Studio is idle.
- Improves MP4 renderer cleanup after completion and cancellation.
- Improves Cancel to Render Again reliability.
- Reduces console and process clutter during video export.
- Improves renderer shutdown when Velvet Wire Studio closes.

Velvet Wire Studio remains an unsigned Windows x64 desktop application using Project Format v2.
