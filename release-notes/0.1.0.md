# Velvet Wire Studio 0.1.0

Velvet Wire Studio 0.1.0 is the initial public release of an offline-first Windows desktop application for creating and exporting cinematic conversations.

## Highlights

- Character creation and multi-character conversation authoring
- Cinematic In-Game IM phone presentation
- Integrated Player Replies
- Project Music saved with the project
- Custom incoming-message and reply sound effects
- PNG export
- MP4 export with supported 30 FPS and 60 FPS settings
- Portable `.velvetwire` Project Format v2
- Offline ordinary use with no account required
- Supported upgrade path for future installers
- Same-version Repair/Reinstall support
