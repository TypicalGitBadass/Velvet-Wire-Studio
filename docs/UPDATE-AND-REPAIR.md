# Update, Repair, and Uninstall

## Upgrade

Future Velvet Wire Studio installers are designed to detect an existing installation and replace the older installed version in place. Manual uninstall should not normally be necessary before upgrading.

Save open work and maintain backups of important `.velvetwire` projects before an upgrade.

## Repair/Reinstall

Running the installer for the version already installed provides the Repair/Reinstall flow. Repair restores application-owned files while retaining user projects and settings according to the application's installer lifecycle design.

## Uninstall

Use the standard Windows Installed Apps interface to uninstall Velvet Wire Studio.

External `.velvetwire` project files are user-owned documents rather than application binaries. Keep them outside the application installation directory. The application uninstall is not intended to remove those external project files.
