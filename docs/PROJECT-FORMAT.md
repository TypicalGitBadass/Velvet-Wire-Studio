# Velvet Wire Project Format

- Current format version: **v2**
- File extension: **`.velvetwire`**
- Purpose: portable Velvet Wire Studio project interchange

A `.velvetwire` file stores a project so it can be saved, reopened, backed up, and moved between compatible Velvet Wire Studio installations.

Keep project files outside the application installation directory and maintain backups of important work. When transferring a project, copy the `.velvetwire` file using the operating system's normal file tools, then open it from Velvet Wire Studio.

Format v2 is the current format for Velvet Wire Studio 0.1.0. Future versions may add compatible format capabilities; release notes will document user-visible migration requirements if they arise.
